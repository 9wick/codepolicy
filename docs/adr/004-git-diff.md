## ADR-004: git diff取得ライブラリの選定

**日付:** 2025-03
**ステータス:** 決定

### 背景

`filter: diff`の実現のために、git diffを取得してどのファイル・行が変更されたかを特定する必要がある。

### 議論した選択肢

**`execa`でgitコマンドを直接実行**
- シンプルで依存が少ない
- diffのパース処理を自前で書く必要がある

**`simple-git`**
- Node.js向けのgitラッパーライブラリとして最も広く使われている
- `git diff`の結果をパースして扱いやすい形で返してくれる
- 変更ファイル・変更行範囲の取得が容易

### 決定

**`simple-git`を採用する。**

### 理由

diffのパース処理を自前で書くコストを避けられる。`simple-git`で取得した変更ファイルと行範囲をtree-sitterに渡してASTから変更関数を特定する、という流れが自然に実装できる。
